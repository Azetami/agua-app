# AguaApp V0.1

Primera versión del proyecto Android/Flutter.

Incluye:
- Pantalla inicial
- Selección Cliente / Chofer
- Registro
- Inicio de sesión
- Datos de cliente solicitados: usuario, contraseña, nombre y apellido, cédula y dirección
- Panel separado para Cliente y Chofer
- Persistencia local temporal para pruebas

IMPORTANTE:
Esta V0.1 es una maqueta funcional local. Todavía NO usa servidor, GPS, mapas, notificaciones ni cuentas multiusuario reales.
La siguiente etapa conectará la aplicación a un backend y base de datos.

Para compilar:
1. Instalar Flutter.
2. Ejecutar `flutter pub get`.
3. Ejecutar `flutter build apk --release`.
4. APK: `build/app/outputs/flutter-apk/app-release.apk`
