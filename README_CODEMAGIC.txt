AGUAAPP V0.1.1 - CODEMAGIC

Esta versión está preparada para compilarse en Codemagic.

Incluye:
- Flutter app
- Cliente / Chofer
- Registro
- Login local
- Paneles separados
- codemagic.yaml en la raíz
- Workflow android-apk
- Generación de APK debug

En Codemagic:
1. Sube/conecta este proyecto.
2. Selecciona el workflow "android-apk" del codemagic.yaml.
3. Inicia el build.
4. Al terminar, descarga el artefacto .apk.

NOTA:
Esta es una V0.1 de prueba. Los datos todavía se guardan localmente en el teléfono.
Aún no están implementados servidor, cuentas multiusuario, GPS, mapas, notificaciones ni solicitudes reales.
